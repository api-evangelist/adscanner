## API status

AdScanner / AEOS publishes NO public developer portal, NO API reference, and NO
machine-readable contract (no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection,
JSON Schema, .proto or WSDL). The company confirms an API exists on its own FAQ:
"our data can be obtained via reporting (pdf, Excel, CSV, json) and API on request."
Access runs through a sales conversation, not a self-serve signup.

The API host api.alleyesonscreens.com resolves (CNAME frontend.alleyesonscreens.com)
and answers HTTP 404 from bare nginx on every unauthenticated path probed, including
/openapi.json, /swagger.json, /api-docs, /docs, /redoc, /graphql and /v1. The
/.well-known/ prefix is blanket-denied with HTTP 403 on both api. and cockpit. hosts.
No base URL can be stated from any published source.
